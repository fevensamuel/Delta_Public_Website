# Logo & Static Assets

Place your custom logo image in this directory:
- Recommended filename: `logo.png` or `logo.svg`
- Update `VITE_APP_LOGO=/logo.png` in `.env.development` and `.env.production` (or set `VITE_APP_LOGO` to your image URL).

The application automatically renders your custom logo image in the Header and Footer with a graceful fallback if no image is loaded.
